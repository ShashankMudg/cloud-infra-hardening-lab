## 🛡️ Core Security Principles Applied

Each project in this lab adheres to the following principles:

- **Least Privilege Access**  
  Fine-grained IAM roles and policies to minimize attack surface.

- **Defense in Depth**  
  Layered security controls across:
  - Edge  
  - Network  
  - Host  
  - Data  

- **Immutability**  
  Enforced via:
  - S3 Object Lock  
  - Infrastructure-as-Code  

- **Continuous Monitoring**  
  Real-time threat detection with automated response mechanisms.
